# 🤖 Лабораторна робота №2: Розробка навчальних матеріалів з інформатики з використанням генеративного ШІ

**Тема:** Генеративний ШІ та Промпт-інжиніринг (Базова програма)
**Цільова аудиторія:** Учні 10-11 класів
**Автор:** Білаш Ольга Олегівна

## 🎯 Мета проекту
Створити повноцінний, адаптивний та інтерактивний навчальний веб-додаток для ознайомлення старшокласників з принципами роботи Великих мовних моделей (LLM) та основами написання ефективних запитів (промпт-інжинірингу). Проєкт розміщено на GitHub Pages і він відповідає всім стандартам доступності (WCAG) та сучасного UX/UI дизайну (Glassmorphism, Dark/Light Mode, Gamification).

🛠 Використані інструменти Штучного Інтелекту
Для створення даного контенту були застосовані наступні ШІ-інструменти:

Google Gemini / ChatGPT: Розробка навчального плану, генерація теоретичного тексту, створення багаторівневих практичних завдань та інтерактивних тестів. Створення модульного JS-коду для тренажера.

Nana Banana 2 / Midjourney: Генерація тематичного візуального контенту (ілюстрації еволюції ШІ, концептів галюцинацій).

Luma Dream Machine: Створення демонстраційного навчального відео-контенту.

Mermaid.js: Програмна генерація блок-схем алгоритму токенізації.

⚠️ Примітка: Усі згенеровані матеріали пройшли ретельну перевірку на достовірність (фактчекінг), були відредаговані та методично адаптовані під когнітивні особливості учнів 10-11 класів.

🚀 Основний функціонал (Технічна реалізація)
Progress HUD (Гейміфікація): Глобальний віджет відстеження XP та Рівня користувача, що зберігається в localStorage.

AI Prompt Evaluator: Вбудований у сторінку тренажер, який аналізує введені промпти за допомогою Regex-логіки та нараховує бали.

Smart Quiz: Інтерактивний тест з миттєвим зворотним зв'язком та інтеграцією з системою XP.

PWA Ready: Наявність manifest.json для встановлення проєкту як додатка.
