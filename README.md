# Навчальний модуль: Генеративний штучний інтелект та основи промпт-інжинірингу

**Цільова аудиторія:** Учні 10-11 класів (Поглиблений рівень)
**Автор розробки:** [Білаш Ольга Олегівна]

## 🎯 Мета модуля
Ознайомити учнів з принципами роботи генеративного штучного інтелекту, сформувати базові навички ефективної взаємодії з великими мовними моделями (промпт-інжиніринг) та обговорити етичні аспекти використання ШІ.

## 📚 Очікувані результати
Після завершення модуля учні зможуть:
1. Пояснювати базові принципи роботи LLM.
2. Створювати ефективні та структуровані промпти.
3. Критично оцінювати згенерований контент (галюцинації ШІ).

## 🛠 Використані інструменти генеративного ШІ (для викладача)
При створенні цього навчального модуля використовувались:
* **Claude 3.5 Sonnet / Gemini:** генерація теоретичного матеріалу, глосарію, розробка тестів.
* **Структура та форматування:** Markdown, HTML/CSS для GitHub Pages.
