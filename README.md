# 🤖 Навчальний модуль: "Генеративний штучний інтелект та основи промпт-інжинірингу"

**Дисципліна:** Інформатика
**Цільова аудиторія:** Учні 10-11 класів (поглиблений рівень)
**Автор розробки:** Білаш Ольга Олегівна, студентка 4 курсу

---

## 🎯 Мета та опис проєкту
Цей проєкт є комплексним навчальним модулем, розробленим у рамках Лабораторної роботи №2 з дисципліни "Методика навчання інформатики".
Головна мета — ознайомити старшокласників з принципами роботи Великих мовних моделей (LLM), сформувати навички створення ефективних запитів (промпт-інжиніринг) та розвинути критичне мислення при аналізі згенерованого штучним інтелектом контенту (виявлення галюцинацій ШІ).

## 🗂 Структура репозиторію та навігація
Навчальні матеріали розділені на логічні блоки для зручності використання:

* 📚 **[Теорія (theory/)](theory/)**
  * `main-content.md` — Базові концепції GenAI та LLM.
  * `examples.md` — Приклади хороших та поганих промптів.
  * `glossary.md` — Словник основних термінів.
* 🛠 **[Практика (practice/)](practice/)**
  * `tasks.md` — Практичні завдання різного рівня складності.
  * `labs.md` — Лабораторна робота з генерації візуального контенту.
  * `projects.md` — Творчі проєкти (створення ШІ-асистента).
* ✅ **[Тестування (tests/)](tests/)**
  * `self-check.md` — Інтерактивний тест для самоперевірки.
  * `assessment.md` — Критерії оцінювання практичних робіт.
* 📎 **[Ресурси (resources/)](resources/)**
  * `links.md` — Корисні посилання для поглибленого вивчення.
  * `images/` — Ілюстрації та інфографіка до курсу.
* 🎨 **Дизайн та інтерактив**
  * `styles/custom.css` — Базові стилі оформлення.
  * `scripts/interactive.js` — Скрипти для інтерактивних елементів.
