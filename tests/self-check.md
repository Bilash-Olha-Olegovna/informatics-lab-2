# Інтерактивний тест: Перевір себе

Цей тест містить питання різних форматів для комплексної перевірки знань.

### Частина 1: Вибір однієї правильної відповіді
**1. Що означає абревіатура LLM?**
- [ ] A) Low Level Machine
- [x] B) Large Language Model
- [ ] C) Logical Learning Mechanism
- [ ] D) Limited Language Matrix

### Частина 2: Правда чи Брехня (True/False)
**2. Генеративний ШІ бере готові відповіді з прихованої бази даних, схожої на Вікіпедію.**
- [ ] Правда
- [x] Брехня *(Пояснення: ШІ генерує текст слово за словом на основі ймовірностей, а не копіює його).*

### Частина 3: Встановлення відповідності
**3. З'єднайте елемент промпту з його прикладом:**
1. Роль
2. Контекст
3. Завдання
4. Формат

*Варіанти:*
- А) "Напиши пояснення у вигляді таблиці з трьох колонок." *(Відповідь: 4)*
- Б) "Дій як старший розробник програмного забезпечення." *(Відповідь: 1)*
- В) "Поясни, як працює цикл while." *(Відповідь: 3)*
- Г) "Я студент першого курсу і маю проблеми з розумінням логічних операторів." *(Відповідь: 2)*

### Частина 4: Відкрите питання
**4. Прочитайте запит: *"Напиши твір про космос"*. Використовуючи знання з промпт-інжинірингу, перепишіть цей запит так, щоб він став максимально ефективним.**
*(Учні мають написати свій варіант із застосуванням ролі, контексту, формату та обмежень).*
