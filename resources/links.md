# 🔗 Корисні ресурси та ШІ-інструменти

Для виконання практичних робіт та поглибленого вивчення теми рекомендуємо використовувати наступні ресурси:

### 🤖 Текстові генеративні моделі
* [ChatGPT (OpenAI)](https://chatgpt.com/) — базова модель для роботи з текстом та кодом.
* [Claude 3.5 Sonnet (Anthropic)](https://claude.ai/) — найкращий вибір для аналізу великих текстів та програмування.
* [Google Gemini](https://gemini.google.com/) — ШІ з доступом до актуальної інформації в інтернеті.

### 🎨 Генерація зображень
* [Microsoft Copilot (DALL-E 3)](https://copilot.microsoft.com/) — безкоштовна генерація зображень за описом.
* [Nana Banana 2](https://nana-banana.org) — просунута модель для створення високоякісного візуального контенту (використовувалась для ілюстрацій цього курсу).

### 🎓 Навчальні курси
* [Prompt Engineering Guide](https://www.promptingguide.ai/uk) — найповніша відкрита база знань з написання промптів.
